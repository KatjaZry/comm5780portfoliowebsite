Weekly Reflection

My weekly workshop reflections

Week 2 Workshop:

This week, we were asked to create our own website using either CampusPress or GitHub Pages. I chose to build my website using VS Code and publish it through GitHub Pages because I wanted to learn more technical skills and gain hands-on coding experience. I had some experience with VS Code before, but it has been a while since I last used it, so I thought this would be a good opportunity to refresh my knowledge and improve my coding skills. Compared with CampusPress, using VS Code allows me to learn more about HTML, CSS and JavaScript, better understand how websites work behind the scenes, and have more freedom to customise my website.

Building a website from scratch requires a lot of time, so I decided to use one of the recommended templates from HTML5 UP as a starting point. Based on the existing code, I customised the content and design to suit my needs while learning more about the structure of the website.
At first, I found it challenging to identify which parts of the code controlled different sections of the website. I used AI to help me understand the code structure and locate relevant sections more efficiently. I also learned to use a new feature in VS Code that allows me to search for keywords and jump directly to specific lines of code. These methods helped me work more efficiently while developing my understanding of web development. This experience also made me reflect on some of the ideas discussed in the lecture. Technology and society are closely connected and influence each other. While AI can be a useful tool for coding, I realised the importance of thinking critically about its suggestions rather than relying on them completely. This raised a broader question for me: how can we use AI responsibly to create a positive impact on our work and studies while maintaining our own judgement and control?

About Me
